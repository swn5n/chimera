        Lending

        Bigger models leave less memory for you while you're connected. 0 means no limit.

        When you start a long task, your other devices connect to pitch in, then stand down when it's done.

        For your own long tasks with “Keep going until done”: a Blender or Python script in each round's result runs on this computer before Hydra accepts it, in a sandbox with no network, your home folder hidden and writes only to a throwaway folder (on a Mac it can't start other programs either). A crash sends its error into the next round. Models on other people's computers help write these scripts; they only ever run here, never on theirs, and nobody else's scripts run on yours.

        This computer can't make that sandbox (it needs macOS, or bwrap on Linux), so its long tasks' scripts aren't run.

        Make a Head

        A Head lets the whole pool use a program or a server on this computer. Fill this in instead of writing code: Chimera saves it as an ordinary Head folder, sandboxed like any other.

        1 · What it is

        Write it in the words people would use. A model reads this to decide which requests go to your Head.

        2 · What goes in and comes out

        It gives back

        3 · How it runs

        Start with the program (its full path if Terminal needs one) and put the placeholders where the request's parts go. The program saves its result in {{out}}.

        Put each placeholder in quotes. A value that is only a placeholder keeps its type: "{{steps}}" sends the number 30.

        4 · Settings people can ask for (optional)

        The fastest model on this computer reads them from each request ("make it darker" sets strength to 0.8). Use each one as {{its_name}}.
